# 5—10分钟讲解安排

建议时长约8分钟。提供的演示使用实际工作台画面和本地合成中文配音；真实录音内容不放入公开演示画面。可按下列脚本录制个人讲解版本。

| 时间段 | 页面与操作 | 讲解重点 |
| --- | --- | --- |
| 0:00—0:55 | 通话分析首页 | 背景、15字段目标、三个入口、证据优先 |
| 0:55—1:45 | 载入并分析题目示例 | 角色区分、未知留空、模型真实运行 |
| 1:45—2:40 | 原文证据与企业候选 | 品牌不等于工商主体、来源与歧义 |
| 2:40—3:40 | 意向评分 | 五维权重、高意向门槛、明确拒绝、意向与支持度分开 |
| 3:40—4:35 | 标准JSON | 15字段、约数、未知与时间规则 |
| 4:35—5:30 | 人工审核与记录 | 规范约数、退回补充、修改前后快照、核验词库 |
| 5:30—6:25 | 筛选、多选和批量预览 | 防误改、版本冲突、整批回滚 |
| 6:25—7:20 | 录音输入入口 | 本地音频、机器转写、逐段角色标注、传输边界 |
| 7:20—8:20 | 效果验证 | 回归测试、示例验证、真实金标尚缺、后续优化 |

## 演示注意

- 题目示例与合成案例始终保留来源标签；不伪装真实客户。
- 企业无核验依据时展示“待补充”，不临时填一个看似完整的工商名称。
- 展示一次失败或不确定案例，说明系统如何将问题交给人工。
- 演示审核操作仅作用于题目或合成样本，不能声称形成真实企业金标。
- 真实材料的外部模型验证仅在取得具体授权后进行。
- 先展示解决的问题，再展示实现细节；最后说明已验证范围与局限。

完整配音逐字稿见 `scripts/narration.json`。如需个人录屏，按此脚本操作本地页面，替换合成配音即可。
