# 提交清单

- 设计文档：`docs/DESIGN.md`；字段定义、验收与规划有独立文件。
- DEMO交付（二选一）：可访问的在线Demo，或 **GitHub仓库链接＋运行说明**。根据用户补充的完整原文，本项目选择后者，无需为本次交付继续租用服务器。仓库地址：[https://github.com/icebz32299-wq/AI-SDR-Agent](https://github.com/icebz32299-wq/AI-SDR-Agent)。提交前确认远端代码完整且能按README复现。
- 运行说明：见根目录 `README.md`；说明Python版本、依赖安装、模型密钥配置、语音模型准备、启动与停止方式。仓库方案需要评审自行运行，`http://127.0.0.1:8765`是运行后的本机地址，不是公网链接。
- 录屏文件：需按最终提交版本录制并确认；本地运行版本也可以录屏。`output/AI-SDR-Agent-demo.mp4`是旧演示，不直接视为最新交付。
- 验证证据：`docs/evaluation.json`、`docs/test-results.xml` 和页面截图。
- 材料处理：原始录音、私有处理清单及转写全文留在本地工作区，不进入可分享源码。可分享版本的`docs/MATERIALS.md`仅说明材料使用方式；评审可以上传自己的测试文件。

## 明确边界

1. 主模型通过用户提供的代理接入；记录实际返回模型名，不能仅凭请求名验证供应商底层版本。
2. 外部企业候选搜索适配器已提供，但本机未配置搜索密钥，未做真实联网验证。
3. 品牌候选库不是工商库，未知主体进入审核，不编造企业全称。
4. 机器转写未人工逐字核验，未自动声称完成可靠说话人分离。
5. 真实通话未形成独立人工金标；没有足够依据报告主体准确率和意向Macro-F1。
6. 本地代码和端到端交互已验证，不等于生产多用户CRM系统。对外部署应配置访问保护。
7. 按用户补充的完整原文，邮件交付为设计文档、DEMO交付链接及录屏文件；DEMO链接可采用GitHub仓库＋运行说明，不强制上线。采用仓库方案时源码需供评审访问，但不必另外将整个源码文件夹作为邮件附件。未经用户明确指示不发布仓库或发送邮件。

## 仓库发布前检查

1. 排除`.env`及其他私密配置、runtime、原始录音、真实转写、客户数据库、上传文件和含隐私的截图/日志。运行数据不能因提交GitHub而公开。
2. 检查文档和验证报告，公开内容只保留题目允许公开的材料与明确标识的合成案例；发布仓库前另行准备可分享版本，不直接将整个工作区上传。
3. 从全新目录获取仓库，按README安装、准备语音模型和配置自己的API密钥，验证文本与录音分析、人工/批量审核、导出和停止功能。
4. 检查评审可以访问仓库。私有仓库需要授予访问权限；不能把评审打不开的私有链接当作完成交付。
