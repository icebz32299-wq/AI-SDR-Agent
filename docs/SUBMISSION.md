- 设计文档：`AI-SDR-Agent项目设计文档.pdf`，同内容正文见 `DESIGN_SUBMISSION.md`。
- DEMO：公开仓库 https://github.com/icebz32299-wq/AI-SDR-Agent ，运行步骤见 `RUNNING.md`；本地地址仅在程序启动后可访问。

源码不包含开发者密钥、原始客户录音或私有运行记录。接收者需安装依赖、配置自己的模型接口，并在使用录音功能前准备语音模型。
